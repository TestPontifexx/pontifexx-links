# Pontifexx Nederland — linkpagina

Deze repository bevat een gratis, mobielvriendelijke linkpagina in de stijl van het aangeleverde Pontifexx-ontwerp.

## Publiceren (eenmalig)

1. Open **Settings** in deze repository.
2. Kies in het menu **Pages**.
3. Bij **Build and deployment** kies je **Deploy from a branch**.
4. Selecteer branch **main** en map **/(root)** en klik op **Save**.
5. Wacht tot GitHub Pages de site heeft gepubliceerd. De verwachte adresvorm is `https://testpontifexx.github.io/pontifexx-links/`.

## Aanpassingen

Je kunt Brechtje gewoon in ChatGPT vragen om tekst, knoppen, links of de vormgeving te wijzigen. ChatGPT kan de bestanden in deze repository rechtstreeks aanpassen zodra de GitHub-verbinding actief is.

De tekst staat in `data/content.json`; de knoppen en bestemmingslinks staan in `data/links.json`. De pagina zelf staat in `index.html`.

## Controleer de social links

De website-, LinkedIn- en e-maillinks zijn ingevuld. Controleer vóór het delen ook even of de Instagram- en YouTube-adressen overeenkomen met de officiële Pontifexx-kanalen.

Er zijn geen betaalde Linktree-functies, externe scripts of externe lettertypen nodig.
